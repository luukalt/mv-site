# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please follow these steps:

1. Do not open a public issue.
2. Report it privately via the repository's **Security → Report a vulnerability** tab on GitHub.
3. Include the details of the vulnerability and any steps to reproduce it.

We take security issues seriously and will respond as quickly as possible to any reports.

## Supported Versions

Only the latest version of the repository is supported with security updates. Ensure you are using the latest release or branch.

| Version | Supported          |
|---------|--------------------|
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Security Updates

This repository uses tools to manage security vulnerabilities, including:
- **Dependabot** to monitor dependencies for security updates.
- **Static analysis tools** such as CodeQL.

## General Guidelines

- Ensure no sensitive information like API keys or passwords are included in the repository.
- Regularly update dependencies and monitor for vulnerabilities.
